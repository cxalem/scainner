# Replay corpus from open sources
Multi-brand plan Phase 3 (P3.1). Every fixture under `apps/desktop/src-tauri/tests/fixtures/{brand}/{platform}/{shape}/` that is not the project's own capture was imported by `scripts/import_obdb_fixtures.py` from `scripts/SELECTION.json`; `python3 scripts/import_obdb_fixtures.py --corpus <root> --check` reproduces it byte for byte. Each fixture is three files: `elm/<name>.json` (ELM replay, `ElmDriver::from_replay_json` format), `correlation/<name>.json` (`HypothesisInput`, one sample per verified case, payload after the echoed identifier, no references) and `correlation/<name>.expected.json` (signal definitions, expected values per sample, provenance).
Corpus size: 449 KB in 177 files across 9 brand directories; 706 verified cases.

## What the importer verifies
A case is imported only if every `expected_values` entry recorded by the source reproduces from the reassembled response with OBDb's decoder semantics (`bix`/`len`/`sign`/`mul`/`div`/`add`/`min`/`max`/`blsb`/`map`, data after the service echo). Cases that do not verify (mode-01 bleed-through, malformed frames, undefined signals) are skipped and never written. Identification DIDs (`F1xx`/`F2xx`) are excluded from the OBDb import; the ECU strings from opendbc are part/software numbers, not serials or VINs, and every replay is marked `contains_vehicle_identifiers: false` after review.
Findings while importing: the address-extension byte precedes the PCI in every recorded `e=` frame; `|ta=` responses arrive on `pri<<24 | rax` (e.g. `17FE0076`), and the request id used for the replay's `ATSH`/`ATFCSH` is `pri<<24 | hdr<<8 | ta` (`17FC0076`), which is the ISO 15765-2 extended format the pack's open item in RESEARCH.md describes; the corpus cannot confirm the request side, only the response id. `DAxx` headers without a recorded `rax` answer on `18 DA F1 xx`.

## Regenerating
```
python3 scripts/import_obdb_fixtures.py --corpus <root>            # rewrite
python3 scripts/import_obdb_fixtures.py --corpus <root> --check    # verify
```

`<root>/raw/OBDb/<Repo>/` must hold the repo at the commit in its `COMMIT` file (tests, signalsets, `LICENSE`), plus `OBDb/<Brand>/` and `OBDb/SAEJ1979/` for brand-level signal definitions; `<root>/raw/opendbc/` holds `COMMIT`, `LICENSE` and `car/<brand>/fingerprints.py`. Changing `scripts/SELECTION.json` is the only supported way to add or drop fixtures.
